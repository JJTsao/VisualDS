// HOW IT WORKS

  • 內部維護鄰接表 adj[u] = [(v, w)…]（無向 → 雙向都加）
  • BFS：queue 逐層擴展，入列時 amber 高亮、出列處理時轉綠
  • DFS：遞迴（call stack）深入到底再回溯
  • Dijkstra：距離初始化為 ∞、Node 0 為 0；鬆弛邊時更新鄰居距離標籤
  • Dijkstra 結束後以粗綠線標出最短路徑樹
