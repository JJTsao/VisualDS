過程式測驗_

在隨機生成的題目上,逐步手動執行演算法 —— 系統在伺服器端逐步判分, 考的是過程而非只看最終答案。先輸入學號,再選一個章節開始。

二元搜尋樹　Binary Search Tree
BSTBST 刪除 搜尋目標節點 → 判斷葉 / 一子 / 兩子 → 用中序後繼解決刪除。 開始作答 → BSTBST 插入 從 root 逐節點比較大小,一路往左 / 右,找到正確的插入位置。 開始作答 → BSTBST 走訪 依前序 / 中序 / 後序規則,逐步報出節點的拜訪順序。 開始作答 →
圖　Graph
GraphDijkstra 最短路徑 逐輪挑出暫定距離最小的節點,鬆弛鄰居、更新距離,直到全部確定。 開始作答 → GraphDFS 走訪 沿深度優先規則,逐步點出節點的拜訪順序。 開始作答 →
排序　Sorting
SortingBubble Sort 相鄰兩元素比較,逐步判斷該交換或保留,每輪沉一個到尾端。 開始作答 → SortingSelection Sort 每一輪在未排序段中,點出最小值的格子放到前面。 開始作答 → SortingMerge Sort 切分後合併兩段子陣列,逐步判斷每一步該取左邊或右邊。 開始作答 →
